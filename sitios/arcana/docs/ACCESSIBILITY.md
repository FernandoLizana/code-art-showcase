# Accesibilidad

## Implementado

- Navegación por teclado en niveles
- Etiquetas ARIA en componentes interactivos
- `prefers-reduced-motion` respetado en CSS
- Configuración de tamaño de texto

- Temporizadores mínimos de 5 segundos en diseño
